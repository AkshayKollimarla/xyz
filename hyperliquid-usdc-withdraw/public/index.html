Hyperliquid USDC Withdraw

Local-only tool. Your private key lives only in this machine's .env file, loaded server-side — it is never sent over the network.
Read before use:
- Run this only on your own machine (npm start, then open http://127.0.0.1:3001). The server binds to localhost only.
- The private key must be your Hyperliquid master account key (the one behind MetaMask) — API/agent wallets cannot authorize withdrawals.
- The destination address can be any address — Hyperliquid's withdraw action lets you specify it directly, so funds go straight there without an extra Arbitrum-to-Arbitrum hop.
- Withdrawals only pull from your main Perps balance. If you also hold USDC in Spot or in a HIP-3 dex listed in EXTRA_PERP_DEXES, this tool automatically sweeps those into Perps first, so a blank-amount withdrawal really does move everything.
- There is a small (~$1) withdrawal fee deducted automatically, and it takes a few minutes to land on Arbitrum.
- If a HIP-3 dex has open positions, their margin isn't withdrawable until closed — this tool can show them and place reduce-only market orders to close them all, freeing that margin. This is separate from withdrawing and requires typing a confirmation phrase, since it realizes P&L and executes real trades.
- Double-check the destination address before confirming. This is irreversible.
